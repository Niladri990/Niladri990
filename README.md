## 👨‍💻 About Me

Full-stack developer and **B.Tech Computer Science & Engineering** student, building
**Java + Spring Boot** backends and **React** frontends with a focus on **clean code,
minimal UI, and strong architecture**. I care about making systems that are
**secure by default** — a JWT should never be trusted without verification, and a
role check should never be an afterthought.

- 🎓 **Currently:** B.Tech student in **Computer Science & Engineering**
- 💻 **Skilled in:** Full-Stack Development with **Java, Spring Boot, React, AWS**
- 🧩 **I focus on:** JWT auth, role-based access, REST API design, and responsive UIs
- 🚀 **Passionate about:** Building scalable apps & solving problems
- ✨ **Philosophy:** Clean code, minimal UI, and strong architecture
- 🌏 **Looking for:** Full-stack or backend roles — India or global remote
